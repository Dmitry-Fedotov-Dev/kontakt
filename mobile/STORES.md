# Открытое радио — публикация в Google Play и App Store

Приложение — обёртка Capacitor 8 вокруг `https://openline.one/radio/`: страница та же, что на
сайте, обновления сайта сразу видны в приложении без новой версии. Нативное сверху — только то,
без чего радио не работает как приложение: эфир в фоне (Android — сервис с уведомлением и кнопкой
«Стоп», iOS — фоновый режим `audio`), микрофон для ведущего, иконки и заставки, название на
двух языках. Новых функций нет.

| | Android | iOS |
|---|---|---|
| Идентификатор | `one.openline.radio` | `one.openline.radio` |
| Название под иконкой | «Открытое радио» (ru, uk, be, kk, ky), иначе «Open Radio» | «Открытое радио» (ru), иначе «Open Radio» |
| Минимальная версия | Android 7 (API 24), цель — API 36 | iOS 15, только iPhone, портрет |
| Сборка | GitHub Actions `mobile.yml`: APK и AAB, подписанные ключом загрузки | GitHub Actions: проверочные сборки; с ключом App Store Connect — TestFlight |

## Что нужно от владельца

1. **Google Play Console** — аккаунт разработчика ($25 разово), https://play.google.com/console.
2. **Apple Developer Program** — $99 в год, https://developer.apple.com/programs/. Проверить, что
   регистрация и оплата доступны из Кыргызстана.
3. **Ключ загрузки Android** уже создан: `C:\Users\cosmo\open-radio-keys\upload.p12` и пароль в
   `password.txt` рядом (в git их нет, в секретах GitHub — есть). **Сделайте резервную копию**
   папки в надёжное место (менеджер паролей, зашифрованный диск). Потеря не смертельна: в Google
   Play включается App Signing — подписью приложения владеет Google, а ключ загрузки можно
   сбросить через поддержку.
   SHA-256 сертификата загрузки: `39:16:B6:48:4F:1F:22:15:23:22:3B:55:55:F2:F3:BE:BD:F4:BE:CB:59:21:76:6B:F0:9D:60:B5:37:01:AC:13`.

## Google Play — по шагам

1. Play Console → «Создать приложение»: название «Открытое радио», язык по умолчанию — русский,
   приложение, бесплатно.
2. Скачать AAB из последнего прогона `mobile` в GitHub Actions (артефакт
   `open-radio-android-…`, файл `app-release.aab`).
3. «Тестирование» → «Внутреннее тестирование» → новый выпуск → загрузить AAB (при первой загрузке
   согласиться на Play App Signing). Добавить себя в тестировщики, поставить с телефона, проверить
   (ниже — что проверить).
4. Заполнить «Содержание приложения» (ответы ниже), страницу в магазине, затем «Рабочая версия».
   Новые личные аккаунты Google требуют закрытого теста: 12 тестировщиков 14 дней подряд, прежде
   чем пустят в рабочую версию.

## App Store — по шагам

1. App Store Connect → «Мои приложения» → «+»: платформа iOS, имя «Open Radio» (локализация ru —
   «Открытое радио»), основной язык — русский, Bundle ID `one.openline.radio` (сначала создать его
   в Certificates, Identifiers & Profiles).
2. «Пользователи и доступ» → «Интеграции» → ключ App Store Connect API с ролью App Manager. В секреты
   репозитория: `ASC_KEY_ID`, `ASC_ISSUER_ID`, `ASC_KEY_P8` (содержимое .p8), `APPLE_TEAM_ID`.
   Следующий прогон `mobile` сам соберёт архив и выгрузит в TestFlight.
3. TestFlight → проверить на iPhone → заполнить страницу, «Конфиденциальность приложения» (ниже),
   отправить на проверку.

## Анкеты

### Google Play — «Безопасность данных»
- Собирает ли приложение данные: **да** — идентификатор устройства в смысле Play: случайный номер
  в куке `kontakt_id`, для **защиты от мошенничества, безопасности и соблюдения правил** (баны).
  Не передаётся третьим лицам, шифруется при передаче (HTTPS), запрос на удаление — очистка данных
  приложения.
- Аудио: **не собирается** — голос ведущего передаётся вживую и не сохраняется (в Play это
  «передача без сбора», если спросят — эфирный звук не хранится).
- Местоположение, контакты, финансы, личные данные, история — **нет**.
- Реклама — **нет**. Аналитика — **нет**.

### Google Play — прочее
- Целевая аудитория: **18+** (пользовательский эфир).
- Пользовательский контент: **да** — есть жалобы, модерация, правила (ссылка на
  `terms.html`), бан нарушителей.
- Сервис переднего плана `mediaPlayback` и `microphone`: воспроизведение эфира в фоне по действию
  пользователя; микрофон — только когда пользователь ведёт эфир. Видео-демо для формы: включили
  станцию → погасили экран → звук идёт, в уведомлении «Стоп».
- Возрастной рейтинг (IARC): общение пользователей — да; обмен местоположением — нет;
  неконтролируемый контент от пользователей — да (с модерацией). Ожидаемо 16+/18+.

### App Store — «Конфиденциальность приложения»
- Data Used to Track You: **нет**.
- Data Linked to You: **нет**.
- Data Not Linked to You: **Identifiers → Device ID** (случайный номер для модерации),
  назначение — App Functionality.
- Возрастной рейтинг: **17+** (неограниченный пользовательский контент). Пользовательский контент:
  есть жалоба (кнопка «Жалоба»), правила, бан нарушителей — это требование правила 1.2.

## Что проверить на устройстве перед отправкой
1. Ручка крутится, станция ловится, звук есть.
2. Погасить экран — эфир продолжается (Android: уведомление «Эфир» с кнопкой «Стоп»; iOS: плеер на
   экране блокировки).
3. «Стоп» в уведомлении глушит звук; касание экрана возвращает.
4. «Вещать»: микрофон спрашивает разрешение, ведущий выходит в эфир, слушатель на другом
   устройстве его слышит; погасить экран у ведущего — эфир не рвётся.
5. Ссылка «Поделиться» открывается у друга в браузере.
6. Без интернета — экран «Нет связи с эфиром».

## Известное и не проверенное
- Сборки только в CI: на машине владельца нет Android SDK и Xcode, на устройствах не проверялось.
- Выгрузка в TestFlight написана по документации xcodebuild и не запускалась — нет ключа Apple.
- iOS: лишь «Открытое радио» и «Open Radio» в названии; плеер на экране блокировки зависит от
  того, как WKWebView отдаёт Media Session — проверить на iPhone.
- Правила App Store 4.2 («просто сайт»): довод в пользу приложения — фоновый эфир и плеер на
  экране блокировки, микрофон ведущего. Если отклонят — следующий шаг из плана: «ЗВУК ТЕЛЕФОНА»,
  push «эфир начался».
