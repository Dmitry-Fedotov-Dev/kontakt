# CLAUDE.md — Контакт (Kontakt)

Контекст для Claude Code. Читать перед любой правкой.

## Что это

Голосовая рулетка: снимаешь трубку — говоришь со случайным человеком, только голос и
звук старой линии. Три сервиса на Go: **web** (страница, прокси), **signal** (SIP,
очередь, жалобы), **media** (RTP, мост, гудки, «окраска» линии). Звучание одно — линия 32, выбора в интерфейсе нет.
Второй продукт — **Открытое радио** (`cmd/radio`, `internal/radio`): своя волна 87.5–108.0,
ведущий вещает из браузера (mp3-очередь + микрофон, кодирует сам браузер в G.711 μ-law),
сервер только раздаёт кадры по 160 байт слушателям частоты. Ссылки на волну `/w/101.7?n=&t=` с
картинкой превью `/og/1017.png` (свой пиксельный шрифт 5×7, `pixfont.go`).
Курс — **Kontakt Mesh** (`docs/MESH.md`): Master (control plane) и Worker'ы (data
plane), маршруты по замерам качества. Станция-рулетка становится одним из
потребителей mesh.

Владелец — Дмитрий Федотов (автор xk6-sip). Отвечать по-русски, прямо. Любит чистые
переписывания, а не заплаты; ценит замеры. Документы и комментарии — по-русски,
интерфейс трубки — по-английски.

## Команды

```bash
./scripts/run.sh                                  # media + signal + web → http://localhost:8080
IP=127.0.0.1 SIP_UDP=:5060 ./scripts/run.sh       # плюс SIP/UDP для софтфонов и xk6-sip
go test -race -count=2 ./...                      # всё; e2e поднимает станцию в процессе
bin/k6 run k6/functional/pair.js                  # звонки — только через xk6-sip
./scripts/cluster-tunnel.sh                       # то же за временным туннелем; MONITORING=1 — плюс Grafana
TUNNEL=1 bash scripts/radio.sh                    # радио; обновить, не меняя ссылку: bash scripts/radio.sh update
monitoring/stack.sh up | down                     # мониторинг: Docker / Docker Desktop / без Docker — сам
promtool test rules monitoring/prometheus/tests/radio_test.yml   # тесты тревог (в CI — образом Prometheus)
bin/kontakt-node -role master …                   # узел mesh, см. шапку cmd/kontakt-node
```

Перед «готово»: `gofmt -l .` пусто, `go vet ./...` чисто, `go test -race -count=2 ./...`
зелёный. CI (`.github/workflows/ci.yml`) гоняет то же плюс сценарии xk6-sip и нагрузку.

## Принятые решения

- **Звонковые тесты (функциональные и нагрузочные) — только xk6-sip.** `loadgen`
  остался для замеров CPU/памяти по WebSocket-пути браузера.
- **Ёмкость меряется, а не предполагается.** Никаких констант вида «Cloudflare =
  25 Мбит/с». Полоса — из `kontakt_media_bytes_*_total`, звонков влезет = свободная
  полоса × (1 − запас) / полоса звонка по замеру. Quick Tunnel — только разработка.
- **Master не в data plane.** Его отказ не рвёт связи Worker'ов: допуск подписан и
  проверяется соседями без него.
- **Приватность.** Не писать в журнал IP и ничего о разговорах, голос не хранить. Метрики —
  только счётчики, без названий станций и треков (их задают люди).
- **Дашборды правятся в генераторах** (`monitoring/grafana/gen_*.py`), CI сверяет JSON с ними.
- **Тестировать — по `docs/TEST_CASES.md`**; пометка «на стенде не проверено» — честная.

## Где остановились (04.10.2026)

Предложено и ждёт решения владельца: общая модерация Контакта и радио (одна кука на одном
домене, зоны бана звонки / эфир / всё, временный бан, порог жалоб от разных людей, уровни
доверия для новичков, Telegram-бот для жалоб и тревог, журнал действий) — основа уже есть в
`internal/moderation`. Не сделано: модерация радио, доставка тревог, выбор нового Master'а
(лучше Raft), перенос портов (ждёт список занятых), фазы 2–5 mesh.

## Подводные камни (на все наступили)

- **Кнопки страницы — спрайты на canvas, смена видимых кнопок ждёт конца анимации нажатия**
  (`showButtons`): иначе нажатая кнопка исчезала мгновенно и «вдавленной» её не видно.
- **Порты выбирай через переменные** (`run.sh`, `GRAFANA_PORT`, `PROMETHEUS_PORT`): у владельца
  стандартные порты заняты; `cluster-tunnel.sh` подбирает свободные и пишет цели Prometheus в
  `monitoring/prometheus/targets/`.

- **Скрипты без бита исполнения**, если коммитить из Windows: `git update-index --chmod=+x`.
- **`pkill -f` / `pgrep -f` совпадает с собственной командой** — убивать по PID,
  отобранному по точному имени бинарника.
- **Станция «окрашивает» голос**: порог качества `compareAudio` — по замеру (линия 32 →
  0,76–0,82, порог 0,7), не 0,9 «как в xk6-sip».
- **Фразы абонентов крутятся с момента, когда сняли трубку**: слушать после
  соединения 7 с, иначе целого повтора может не набраться.
- **xk6 читает `K6_VERSION` и `XK6_*` из окружения как свои флаги** — в CI версии
  называются иначе.
- **Счётчик с меткой объявляй с известными значениями** (`CounterVec(…, known...)`):
  ряд, рождённый сразу ненулевым, `rate()` не видит.
- **Mesh: номер сообщения не обязан расти строго** — на одно соединение пишут
  несколько горутин. Защита от повтора — окно (`replayWindow`), иначе пробы молча
  «терялись» и рёбра браковались.
- **Mesh: ребро берётся, только если его объявили оба конца** — иначе последнее
  объявление умершего узла держит маршрут через него до конца TTL.
- **Mesh: опоздавший ответ на пробу — потеря, а не RTT.**
- **Владелец на Windows: WSL + Docker Desktop.** Команды `X=1 cmd` — только в bash (`wsl`), не в
  PowerShell. Git для Windows ставил CRLF и ломал shebang — теперь `.gitattributes` (eol=lf).
- **Docker Desktop: сеть хоста — его виртуальная машина**, а не WSL. Для него
  `docker-compose.desktop.yml` (обычная сеть, порты на localhost, цели через
  `host.docker.internal`); `stack.sh` выбирает сам.
- **`rule_files: rules/*.yml` подхватит и файл тестов** — тесты тревог лежат в `prometheus/tests/`.
- **Node Graph (Grafana 11) падает на пустых данных**: пустой кадр рёбер считается кадром узлов.
  Заглушки через `or on()` в `gen_mesh_dashboard.py`.
- **cloudflared дописывает свой журнал** — перед запуском журнал очищать, иначе находится адрес
  прошлого запуска. Адрес выдавать только после «Registered tunnel connection».
- **Trap на INT без `exit`** только прибирает, и цикл продолжает работу — в `radio.sh` это
  перезапускало сервер по Ctrl+C.
