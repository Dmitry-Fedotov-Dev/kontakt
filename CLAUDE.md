# CLAUDE.md — Контакт (Kontakt)

Контекст для Claude Code. Читать перед любой правкой.

## Что это

Голосовая рулетка: снимаешь трубку — говоришь со случайным человеком, только голос и
звук старой линии. Три сервиса на Go: **web** (страница, прокси), **signal** (SIP,
очередь, жалобы), **media** (RTP, мост, гудки, «окраска» линии 64/32/16/8).
Курс — **Kontakt Mesh** (`docs/MESH.md`): Master (control plane) и Worker'ы (data
plane), маршруты по замерам качества. Станция-рулетка становится одним из
потребителей mesh.

Владелец — Дмитрий Федотов (автор xk6-sip). Отвечать по-русски, прямо. Любит чистые
переписывания, а не заплаты; ценит замеры. Документы и комментарии — по-русски,
интерфейс трубки — по-английски.

## Команды

```bash
./scripts/run.sh                                  # media + signal + web → http://localhost:8080
IP=127.0.0.1 SIP_UDP=:5060 ./scripts/run.sh       # плюс SIP/UDP для софтфонов и xk6-sip
go test -race -count=2 ./...                      # всё; e2e поднимает станцию в процессе
bin/k6 run k6/functional/pair.js                  # звонки — только через xk6-sip
docker compose -f monitoring/docker-compose.yml up -d   # Grafana: localhost:3002
bin/kontakt-node -role master …                   # узел mesh, см. шапку cmd/kontakt-node
```

Перед «готово»: `gofmt -l .` пусто, `go vet ./...` чисто, `go test -race -count=2 ./...`
зелёный. CI (`.github/workflows/ci.yml`) гоняет то же плюс сценарии xk6-sip и нагрузку.

## Принятые решения

- **Звонковые тесты (функциональные и нагрузочные) — только xk6-sip.** `loadgen`
  остался для замеров CPU/памяти по WebSocket-пути браузера.
- **Ёмкость меряется, а не предполагается.** Никаких констант вида «Cloudflare =
  25 Мбит/с». Полоса — из `kontakt_media_bytes_*_total`, звонков влезет = свободная
  полоса × (1 − запас) / полоса звонка по замеру. Quick Tunnel — только разработка.
- **Master не в data plane.** Его отказ не рвёт связи Worker'ов: допуск подписан и
  проверяется соседями без него.
- **Приватность.** Не писать в журнал IP и ничего о разговорах, голос не хранить.

## Подводные камни (на все наступили)

- **Скрипты без бита исполнения**, если коммитить из Windows: `git update-index --chmod=+x`.
- **`pkill -f` / `pgrep -f` совпадает с собственной командой** — убивать по PID,
  отобранному по точному имени бинарника.
- **Станция «окрашивает» голос и на линии 64**: порог качества `compareAudio` — по
  замеру (64 → 0,87–0,92), не 0,9 «как в xk6-sip».
- **Фразы абонентов крутятся с момента, когда сняли трубку**: слушать после
  соединения 7 с, иначе целого повтора может не набраться.
- **xk6 читает `K6_VERSION` и `XK6_*` из окружения как свои флаги** — в CI версии
  называются иначе.
- **Счётчик с меткой объявляй с известными значениями** (`CounterVec(…, known...)`):
  ряд, рождённый сразу ненулевым, `rate()` не видит.
- **Mesh: номер сообщения не обязан расти строго** — на одно соединение пишут
  несколько горутин. Защита от повтора — окно (`replayWindow`), иначе пробы молча
  «терялись» и рёбра браковались.
- **Mesh: ребро берётся, только если его объявили оба конца** — иначе последнее
  объявление умершего узла держит маршрут через него до конца TTL.
- **Mesh: опоздавший ответ на пробу — потеря, а не RTT.**
