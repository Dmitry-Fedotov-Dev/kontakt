# Claude Code звонит вам — kontakt-ring

Закончил работу или ждёт разрешения — Claude Code звонит на трубку «Контакта»: красная трубка
качается, телефон вибрирует, играет трель старого IP-телефона, на дисплее — «Claude Code» и что
случилось. Или звонит напрямую на SIP-устройство: софтфон на ПК (MicroSIP, Linphone), приложение на
телефоне, IP-телефон на столе.

**Ноль токенов.** Это хуки Claude Code (`Stop`, `Notification`): хук — обычная команда, модель для
него не вызывается. Звонок уходит в фоне — Claude Code его не ждёт.

## Как устроено

```
Claude Code ──хук──▶ ring.sh ──POST /api/ring──▶ signal ──WebSocket /api/ring──▶ трубки на рычаге
                        │                                                      (вкладка, приложение)
                        └──kontakt-ring -sip──INVITE/UDP──▶ SIP-устройство (звонит, CANCEL через 20 с)
```

- **Линия** — ваша ссылка из трубки: нажмите «позвонить», на дисплее — `openline.one/?call=<линия>`.
  Это и есть номер телефона: та же ссылка зовёт друзей. Трубка, открытая с этой линией и лежащая
  на рычаге, слушает её и звонит.
- Друг открыл вашу ссылку, а вы не в разговоре — у вас тоже звонит («Вам звонят»), у друга —
  «Вызов…» с длинными гудками. «Ответить» соединяет, «положить» — друг слышит «Вызов отклонён».
- Оповещение не дольше 80 знаков, не чаще раза в 2 с и 120 в час на линию. Текст и линия в журнал
  не пишутся.

## Установка

В Claude Code:

```
/plugin marketplace add Dmitry-Fedotov-Dev/kontakt
/plugin install kontakt-ring@kontakt
```

Ссылку на линию — в `~/.claude/settings.json` (для всех проектов):

```json
{
  "env": {
    "KONTAKT_LINE": "https://openline.one/?call=<линия>"
  }
}
```

или файлом `~/.config/kontakt/ring.env` (строка `KONTAKT_LINE=https://openline.one/?call=<линия>`).
Откройте трубку (сайт или приложение «Контакт») — она слушает линию, пока открыта.

Проверка без Claude Code:

```bash
curl -d 'line=https://openline.one/?call=<линия>' -d from=Claude -d text=проверка https://openline.one/api/ring
```

Ответ `{"listeners":1}` — у одной трубки звонит; `0` — линию никто не слушает.

## Звонок на SIP-устройство

Нужен бинарник `kontakt-ring` в PATH: из релиза `ring-v*`
(https://github.com/Dmitry-Fedotov-Dev/kontakt/releases) или `go build ./cmd/kontakt-ring`.

```json
{ "env": { "KONTAKT_SIP": "sip:100@192.168.1.20" } }
```

Через запятую — несколько устройств; `KONTAKT_LINE` и `KONTAKT_SIP` вместе — звонят все. Звонок идёт
напрямую по UDP (peer-to-peer SIP, без АТС и регистрации): софтфоны принимают такие вызовы по IP
сами. Имя звонящего и тема — «Claude Code: готово — <проект>». Сняли трубку — `kontakt-ring` сразу
кладёт её; не сняли — через 20 с отменяет (`-for`). АТС с паролем (digest) пока не поддерживается.

Руками:

```bash
kontakt-ring -line https://openline.one/?call=<линия> "сборка готова"
kontakt-ring -sip sip:100@192.168.1.20 -for 10s "сборка готова"
```

## Что звонит

| Событие | Текст |
|---|---|
| `Stop` — Claude закончил ответ | «готово — <папка проекта>» |
| `Notification` — просит разрешения | сообщение Claude Code, например «Claude needs your permission to use Bash» |
| `Notification` «ждёт ввода» (через минуту после Stop) | не звонит — о том же уже позвонили |

## Ограничения (честно)

- Трубка в браузере звонит, пока вкладка открыта; звук трели браузер даёт после первого касания
  страницы, вибрация — только на Android (`navigator.vibrate`). Приложение «Контакт» звонит со звуком
  и вибрацией (Haptics, есть и на iPhone), пока открыто или свёрнуто недавно: push-уведомлений
  (FCM/APNs) при закрытом приложении пока нет.
- На стенде не проверено: приложение на живых телефонах, iPhone, MicroSIP/Linphone вживую (SIP
  проверен тестом с поддельным устройством по UDP).
