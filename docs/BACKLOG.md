## Радио

### Звук с погашенным экраном на Android (11.10.2026)
Android Chrome глушит приёмник, когда гаснет экран: звук идёт из Web Audio через `<audio>` с
MediaStream, а такое воспроизведение Android медиаплеером не считает (проверил владелец на телефоне).

- **Временное, в `main` с `ec329cd`:** пока страница спрятана, приёмник играет волну потоком MP3 с
  сервера (`/stream/{freq}`, `stream.go`, ffmpeg на каждого фонового слушателя, не больше 20). После
  гашения экрана — пауза 3–4 с: Chrome начинает поток, накопив ~32 КБ (замер в Chrome 141).
- **Отвергнуто:** заранее запускать поток без звука и при гашении перескакивать к живому краю (в
  headless работает) — двойной трафик у каждого слушателя на Android.
- **Чистое решение:** приёмник всегда играет через настоящий медиаплеер — кадры с сокета кодирует
  сам браузер (WebCodecs, Opus) и кладёт в `<audio>` через MediaSource, шум подмешивается до
  кодирования. Один путь звука, без переключений, без кодеров на сервере; `stream.go` удалить.
  Риски: +0,3–0,5 с задержки (проверить отклик ручки), нет WebCodecs — старый путь. Сначала пробная
  страница на телефоне: не останавливает ли Android JS страницы с погашенным экраном. 1–2 дня.

### PWA и подписка на волну (11.10.2026)
Магазины (Google Play, App Store) на старте не нужны. Вместо них — сайт, который ставится как
приложение: манифест, service worker, кнопка «Установить». Подписка на волну — Web Push (VAPID,
шифрование RFC 8291 на стандартной библиотеке Go): ведущий вышел в эфир — подписчикам уведомление,
не чаще раза в несколько часов на волну. На iPhone — только с экрана «Домой» (iOS 16.4+).
