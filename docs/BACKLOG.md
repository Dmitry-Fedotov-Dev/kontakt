## Радио

### Звук с погашенным экраном на Android (11.10.2026)
Android Chrome глушит приёмник, когда гаснет экран: звук идёт из Web Audio через `<audio>` с
MediaStream, а такое воспроизведение Android медиаплеером не считает (проверил владелец на телефоне).

- **Отвергнуто:** поток MP3 с сервера, пока страница спрятана (`ec329cd`, откачен) — после гашения
  экрана пауза 3–4 с: Chrome начинает поток, накопив ~32 КБ (замер в Chrome 141).
- **Отвергнуто:** заранее запускать поток без звука и при гашении перескакивать к живому краю (в
  headless работает) — двойной трафик у каждого слушателя на Android.
- **Чистое решение:** приёмник всегда играет через настоящий медиаплеер — кадры с сокета кодирует
  сам браузер (WebCodecs, Opus) и кладёт в `<audio>` через MediaSource, шум подмешивается до
  кодирования. Один путь звука, без переключений, без кодеров на сервере.
  Риски: +0,3–0,5 с задержки (проверить отклик ручки), нет WebCodecs — старый путь. Сначала пробная
  страница на телефоне: не останавливает ли Android JS страницы с погашенным экраном. 1–2 дня.

### PWA и подписка на волну (11.10.2026)
Магазины (Google Play, App Store) на старте не нужны. Вместо них — сайт, который ставится как
приложение: манифест, service worker, кнопка «Установить». Подписка на волну — Web Push (VAPID,
шифрование RFC 8291 на стандартной библиотеке Go): ведущий вышел в эфир — подписчикам уведомление,
не чаще раза в несколько часов на волну. На iPhone — только с экрана «Домой» (iOS 16.4+).

### Lo-fi станция с разговорами из Контакта (11.10.2026, после раскрутки Контакта)
Постоянная станция: открытые lo-fi биты, раз в час — случайный разговор из Контакта (1–3 мин).
Сейчас обещаем обратное (голос не храним, о разговорах не пишем), а запись чужого разговора без
согласия обоих — тайна переговоров (ст. 23 Конституции, ст. 138 УК) и биометрия. Поэтому только так:
- отдельный режим «в эфир» — согласие **до** звонка, таких соединяем только друг с другом, в начале
  звонка оба слышат «разговор записывается для радио»; обычный Контакт ничего не пишет;
- запись хранится до решения модерации, каждый может забрать свой разговор (после звонка и позже — по коду);
- модератор слушает, вырезает фрагмент без личных данных, утверждает — без этого в эфир ничего;
- правила и политика конфиденциальности — под режим, до запуска — юрист.
Техника: запись смеси в media только для таких звонков; у станций с сервера — вставка раз в час
(джингл «звонок с линии» + разговор); очередь модерации в админке и кнопки в боте владельца.
Начать можно без записи из Контакта: lo-fi станция и заранее записанные «звонки» знакомых.
