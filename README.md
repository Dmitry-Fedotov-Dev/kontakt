# Контакт
<img width="427" height="900" alt="image" src="https://github.com/user-attachments/assets/ee221aa9-4ef8-4bf3-8cf6-3c27cf632ed8" />

Снимаешь трубку — и говоришь со случайным человеком. Только голос человека в старой телефонной трубке. Собеседник положил трубку — слышишь шум пустого эфира, потом гудки, и вот уже следующий человек.

- Протокол — из браузера по WebSocket (RFC 7118). Можно подключаться с любого устройства через ваш браузер.
- Три сервиса на Go: **web**, **signal**, **media**. Media управляется по gRPC.
- Голос нигде не хранится. У каждого есть право на вечный бан собеседника по куке (в дальнейшем будет бан по железу).
- Сто каналов (50 разговоров) — это 0,22 ядра и 43 МБ ОЗУ, подробности в [LOAD_REPORT.md](LOAD_REPORT.md). канал стоит сети 64 кбит/с, бесплатный канал из коробки (claudflare) предоставляет 25 мбит/с. Максимальный онлайн на таком сервере: 195 одновременных звонков и 390 живых пользователей/абонентов.

## Запуск за минуту

### Запуск на телефоне в Termux:

#### подготовка termux:

предоставьте termux права на файловую систему, на остальное права не нужны (при необходимости снимите галочки с лишних пунктов)
```bash

termux-setup-storage

```

```bash

// Разархивировать в домашнюю папку:
unzip ~/storage/downloads/kontakt.zip

// В первой вкладке (сессии) termux: 
pkg install golang git cloudflared
  ./scripts/run.sh                 
Во второй вкладке (сессии) termux:
  ./scripts/tunnel.sh quick

```

Нужен Go 1.22+. Если `go build` ругается на модули, удалите блок `replace` в `go.mod` и выполните `go mod tidy`.

```bash
./scripts/run.sh
# открыть http://localhost:8080
```

Для проверки вдвоём откройте две вкладки в разных браузерах (или одну в режиме инкогнито). Две вкладки одного браузера станция не соединит: у них одна кука, а значит, это один человек.

**С телефона в локальной сети.** Микрофон браузер даёт только по https, поэтому:

```bash
HTTPS=:8443 ./scripts/run.sh
# на телефоне: https://<IP-компьютера>:8443 и согласиться с предупреждением о сертификате
```

**С обычного SIP-софтфона** (Linphone, MicroSIP, Zoiper):

```bash
SIP_UDP=:5060 ./scripts/run.sh
# в софтфоне позвонить на sip:32@<IP-компьютера>
# 32 — звук линии; можно 64, 16 или 8
```

Софтфон и браузер попадают в одну очередь и слышат друг друга.

## В интернет через Cloudflare

```bash
./scripts/tunnel.sh quick                        # временный https://…trycloudflare.com, аккаунт не нужен
./scripts/tunnel.sh publish kontakt.example.com  # постоянный адрес на своём домене
```

`publish` сам пишет конфиг `cloudflared`, где `/sip` и `/media` идут в сервисы напрямую, мимо `web`-прокси. По CPU это вдвое дешевле. Наружу открывается только туннель: порты 8081, 8082, 8091 и 7002 слушают 127.0.0.1.

## Как устроено

```
браузер ──https──► web :8080 ── страница, вечная кука kontakt_id
   │                  │
   ├─ wss /sip ───────┼──► signal :8081 ── SIP B2BUA, очередь, жалобы, баны, конфиг
   │                  │        │  gRPC :7002
   └─ wss /media ─────┴──► media :8082 ◄─┘ RTP, G.711, эффект линии, гудки и шум
софтфон ── SIP/UDP :5060 ──► signal          RTP/UDP 10000-10200 ──► media
```

**Звонок.** INVITE сразу получает 200 OK: трубку сняли, вы на станции. Дальше media играет гудки через выбранный кодек линии. Signal находит пару и командует media `Bridge`, трубке приходит `INFO {"state":"talking"}`. Собеседник ушёл — 2 с белого шума, затем гудки и следующий человек. Всё это в рамках того же SIP-диалога.

**Эффект линии** (`internal/dsp`). Полоса 300–3400 Гц, затем деградация кодеком:

| Режим | Что делает |
|---|---|
| 64 | G.711 |
| 32 | IMA ADPCM, 4 бита |
| 16 | ADPCM, 2 бита |
| 8 | дельта-модуляция, 1 бит |

Поверх — шипение, фон 50 Гц, редкий треск и лёгкая перегрузка, как у угольного микрофона. Гудки и шум идут через ту же цепочку. Режим можно менять прямо в разговоре.

| Каталог | Что там |
|---|---|
| `cmd/web`, `cmd/signal`, `cmd/media` | три сервиса |
| `cmd/loadgen` | нагрузочный генератор |
| `internal/sip` | разбор и сборка SIP |
| `internal/signal` | B2BUA, очередь, жалобы, транспорты UDP и WS |
| `internal/media` | RTP-точки, мост, тикер гудков |
| `internal/mediaapi` | gRPC-контракт: `media.proto` и стабы |
| `internal/dsp` | G.711, ADPCM, эффект линии, генератор гудков и шума |
| `internal/config` | конфиг с горячей перезагрузкой |
| `internal/moderation` | жалобы и баны |
| `internal/webapp` | пиксельная трубка, правила, прокси |
| `e2e` | сквозные тесты |

gRPC идёт с JSON-кодеком: в среде сборки не было `protoc`. Контракт описан в `internal/mediaapi/media.proto`. Если сгенерировать protobuf-стабы, они заменят `api.go` без изменений в сервисах.

## Жалобы и баны

- При `ban_policy: "instant"` любая жалоба — сразу бан.
- Бан привязан к куке `kontakt_id`: случайные 128 бит, срок 10 лет. В `data/bans.json` лежит только её SHA-256, число карточек и дата.
- Ограничения: пожаловавшегося и нарушителя больше не соединяют, а жаловаться можно не чаще `max_reports_per_hour` раз в час.
- Разбанить: `curl -X POST 'localhost:8091/admin/unban?id=<значение куки>'`.
- **Важно.** Бан по куке обходится очисткой кук или другим браузером. Это защита от случайных хулиганов, а не от упорных.

## Конфиг на лету

`config/kontakt.json` перечитывается сам. Ещё можно `kill -HUP <pid signal>`, `systemctl reload kontakt-signal` или `curl -X POST localhost:8091/admin/reload`. Новый конфиг сначала проверяется: с ошибкой он не применится. Затем в журнале появляется «применю через 1 с: …», и ровно через `apply_delay_ms` он вступает в силу для новых звонков. Идущие разговоры не трогаются.

| Ключ | Что делает |
|---|---|
| `default_line`, `allowed_lines` | звук линии по умолчанию и что показывать в трубке |
| `ban_policy` | `yellow` или `instant` |
| `report_window_sec`, `max_reports_per_hour` | окно и лимит жалоб |
| `max_call_minutes` | ограничение длины разговора, 0 — без ограничения |
| `maintenance` | техработы: новые звонки получают 503 |
| `apply_delay_ms` | задержка перед применением |

## Сервер

Для VPS в `deploy/` лежат systemd-юниты с ограничениями памяти. Собирать можно на своей машине:

```bash
CGO_ENABLED=0 GOOS=linux GOARCH=amd64 go build -trimpath -ldflags "-s -w" -o bin/ ./cmd/web ./cmd/signal ./cmd/media
# ARM: GOARCH=arm64 (или GOARCH=arm GOARM=7)
```
